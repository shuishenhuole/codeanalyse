# CodeStat - 代码量统计工具

基于 Flet 的桌面应用，统计项目中各编程语言的代码行数。支持 40+ 种编程语言，区分代码行/注释行/空行，可导出 JSON / CSV / Word。

## Run the app

### uv

Run as a desktop app:

```bash
uv run flet run
```

Run as a web app:

```bash
uv run flet run --web
```

For more details on running the app, refer to the [Getting Started Guide](https://flet.dev/docs/).
